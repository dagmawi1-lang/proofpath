# STEM2Connect requirements checklist

- Eligibility: student aged 13+; under legal age of majority requires parent/legal guardian permission.
- Solo or team up to 6; each participant may join one team only.
- Track: Education, Healthcare, Sustainability, Scientific Research, or Community Impact. ProofPath targets Education.
- New work must be created during Oct 11–Nov 21, 2026. This project is being started Oct 31, within the allowed period.
- Working solution required; slides/mockups alone do not qualify.
- AI coding assistants permitted with disclosure and attribution in README and Devpost description.
- AI feature recommended but not mandatory. ProofPath's optional AI coach requires server-side provider configuration; deterministic local fallback works without API credits.
- Submit public GitHub repository and README, plus a working demo video no longer than 6 minutes. Live or prerecorded Demo Day accepted.
- Deadline: Nov 21, 2026, 11:59 PM Eastern. Demo Day/winners: Nov 24, 2026.
- Do not collect personal data without consent. Keep source content fictional/sample unless users intentionally add their own research.
